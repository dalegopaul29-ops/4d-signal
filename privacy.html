4D Signal — Privacy Policy

Effective date: November 2026 · 4D Meridian Suite · Contact via the Chrome Web Store listing support channel.

1. What data the extension collects, and from where

  • Meeting audio and transcripts (Pro/Enterprise tiers): captured only when a meeting host explicitly starts Record Mode. Recording is announced to all participants in the meeting by the tool itself - there is no silent recording mode. Audio is processed on the user's device.
  • VoIP call metadata (Enterprise tier): call start/end times and duration, processed locally.
  • Phishing/security telemetry (Meeting Mode): aggregate detection events (e.g. "suspicious link blocked") with no message content.
  • Typing cadence and pointer timing (sensor layer, opt-in): timing statistics only - inter-key intervals and pointer velocity aggregates. Key values, page content, form fields, and passwords are never read; the code path does not exist.
  • Settings and usage counters: stored locally (chrome.storage).

Domains accessed: the extension communicates only with 127.0.0.1 (the locally-installed 4D Signal sidecar on the user's own machine) and, for Enterprise VoIP, the SIP provider the customer themselves configures. No other domains are contacted. There are no analytics endpoints, no telemetry servers, and no 4D Meridian servers of any kind.

2. How data is handled

All captured data is processed and stored locally on the user's device. Transcripts and recordings are stored under the user's control in local or customer-managed storage. The optional local sidecar maintains a tamper-evident audit log of security events on the same machine. Data is encrypted at rest where the feature requires it.

3. How data is used

  • Meeting records are used solely to provide the transcript/recording feature the host explicitly started.
  • Security telemetry is used solely to detect and block phishing and malicious content for the user.
  • Sensor statistics are used solely for behavioral anomaly detection on that workstation.
  • No data is used for advertising, profiling, creditworthiness, or any purpose unrelated to the extension's single purpose.

4. Data sharing

4D Signal sells, shares, rents, or transfers no user data to anyone - ever. There is no third-party analytics, no advertising SDK, no cloud sync. The only network destinations are the user's own local sidecar and the customer-configured SIP provider (Enterprise). Because data never leaves the device except to those user-controlled endpoints, cross-border transfer laws (GDPR Ch. V, POPIA s72) are satisfied by architecture.

5. User rights and data deletion

  • Users can view, export, and delete their recordings and transcripts at any time from the tool.
  • Uninstalling the extension removes its locally stored data.
  • A full local wipe (including cryptographic key destruction, making data unrecoverable) is available in settings.
  • POPIA s23/GDPR access requests: all data is on the user's own device - access is direct via the tool's export function.

6. Consent and transparency

Recording requires explicit host action and announces itself to participants. The sensor layer is off by default and activates only after an explicit, informed opt-in on the workstation, which is logged. Employees are never monitored covertly by this tool.

7. Changes

Material changes to this policy will be reflected in an updated version on this page with a revised effective date.
